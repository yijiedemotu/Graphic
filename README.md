# 图研 · 计算机专业论文图表工作台

一个可在本地运行的毕业论文图表生成网站。所有输入内容仅保存在当前浏览器中，不需要登录，也不会上传到云端。

## 已支持

- UML 类图
- ER 实体关系图
- 系统流程图
- UML 时序图
- 系统用例图
- 系统架构图
- 系统功能模块图
- 论文三线表
- 环境配置表
- 实验数据柱状图、折线图

E-R 图支持简洁文本和 MySQL `CREATE TABLE` SQL 自动解析，可识别表/字段注释、主键和外键关系。所有已完成工具都支持实时预览、独立样式参数、拖拽调整、高清 PNG、可编辑 SVG 和源文件导出。

## 本地运行

需要 Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:3000`。

## 构建检查

```bash
npm run build
```
