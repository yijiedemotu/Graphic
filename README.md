# 图研 · 计算机专业论文图表工作台

一个可在本地运行的毕业论文图表生成网站。所有输入内容仅保存在当前浏览器中，不需要登录，也不会上传到云端。

## 已支持

- 系统用例图
- 系统数据流图（DFD，Gane & Sarson 记法）
- 系统架构图
- 系统功能模块图
- UML 部署图
- ER 实体关系图
- 论文三线表
- UML 类图（关联、依赖、泛化、实现、聚合、组合六类关系符号）
- UML 时序图
- 系统流程图（根据连接关系自动分层排版）
- 环境配置表
- 软件测试用例表
- 实验数据柱状图、折线图（支持正值和负值）
- 完整工作区 JSON 备份与恢复（包含图表文本、样式和拖拽布局）

E-R 图支持简洁文本和 MySQL `CREATE TABLE` SQL 自动解析，可识别表/字段注释、主键和外键关系。所有工具都支持实时预览、独立样式参数、拖拽调整、解析诊断提示、插入 Word 后的字号校准、高清 PNG、可编辑 SVG 和源文件导出。拖拽位置与样式保存在本机浏览器中；「导出备份 / 恢复备份」可把全部图表、样式和排版打包为单个 JSON 文件，用于换机或长期存档。

## 本地运行

需要 Node.js `>=22.18.0`（单元测试直接运行 TypeScript 源文件）。

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:3000`。

## 构建与检查

```bash
npm run build      # 生产构建
npm run typecheck  # TypeScript 检查
npm run lint       # ESLint
npm test           # 解析、存储与排版逻辑单元测试
```

## 部署说明

应用不含服务端逻辑：源文件与样式参数全部留在用户浏览器里。因此静态托管（Cloudflare Pages / 任意静态站点）即可获得与本地一致的行为；一旦引入账号同步，需要另行说明数据上传范围。
