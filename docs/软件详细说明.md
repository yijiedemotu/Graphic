## 1. 软件简介

图研是一款面向计算机科学与技术专业本科毕业论文，尤其是软件开发类论文的本地图表工作台。用户通过结构化文本、表格数据或 SQL 建表语句描述内容，软件实时生成符合论文使用习惯的白底图表，并支持导出高清 PNG、可编辑 SVG 和源文件。

软件采用“隐私优先”的设计：图表解析、排版和导出均在浏览器中完成，输入内容默认只保存在当前浏览器的本地存储中，不需要登录，也不会自动上传 SQL、数据库结构或论文内容。

## 2. 适用场景

- 软件开发类本科毕业论文中的需求分析、总体设计、详细设计、系统实现与系统测试章节。
- 课程设计、软件工程实验报告、项目答辩材料。
- 数据库概念结构设计、UML 建模、环境配置表和实验性能数据整理。
- 将已有 MySQL `CREATE TABLE` 语句快速转换为 E-R 图。

## 4. 运行环境

### 4.1 必要环境

- Node.js 22.13.0 或更高版本。
- npm。
- Chrome、Edge、Firefox 等现代浏览器。

```bash

```

## 5. 界面组成

### 5.1 顶部区域

- 左侧为“图研”品牌标识。
- 中间显示当前图表标题和本地保存状态。
- 右侧提供保存源文件、复制到 Word、导出 SVG、导出高清 PNG 等操作。

### 5.2 导航栏

导航栏按软件开发类论文常见章节顺序排列。每个图表拥有独立的文本和样式参数，修改一种图表不会覆盖其他图表的设置。

### 5.3 图表工作台

- 左侧：图表文本或 SQL 输入区。
- 中间：论文效果预览画布。
- 右侧：当前图表的独立样式参数。
- 左侧与预览区之间：可拖动分隔条，也可收起文本区。

## 6. 通用操作

### 6.1 实时生成

在左侧修改文本后，中间画布会实时更新。以 `@title` 开头的行用于设置图题，例如：

```text
@title 在线选课系统 E-R 图
```

### 6.2 拖动图表元素

- 按住图形的非文字区域即可拖动。
- 靠近画布边缘时，画布会缓慢自动扩展。
- 将元素拖回主体区域后，无限画布会重新适配内容。
- 系统架构图的架构层接近中轴时，会出现竖直吸附引导线。
- 双击图形非文字区域可恢复该元素的默认位置。
- 选中图形后可使用方向键微调，按住 Shift 时移动步长更大。

### 6.3 修改文字

双击画布中的文字会显示编辑框。按 Enter 保存，按 Esc 取消。复杂内容建议直接在左侧源文本中修改；SQL 模式下建议修改表名、字段名或 `COMMENT` 内容。

### 6.4 自动排版与画布

- “自动排版”：清除当前拖动偏移，按当前参数重新生成默认布局。
- “适应全部”：根据当前内容和视窗自动调整预览缩放比例。
- “展开画布”：隐藏编辑区和样式区，使画布占满可用屏幕并居中显示。
- 缩放比例：可使用减号、加号或直接输入百分比。

### 6.5 样式参数

- 整体缩放：同时影响图形布局和导出尺寸。
- 整体间距：控制实体、属性、节点、模块等元素之间的距离。
- 正文字号：默认 14px；五号字约对应 14px。
- 字体型号：中文默认宋体，英文默认 Times New Roman。
- 线条粗细：控制边框线、关系线和连接线的粗细。
- 边框大小：控制实体框、属性框、模块框等图形本身的宽高。
- 显示图题：决定导出时是否保留图题。
- 彩色模式：默认关闭，即白底黑字；开启后使用淡色区分元素。
- 显示主键：仅在 E-R 图页面提供。
- 重置参数：只重置当前图表，不影响其他页面。

### 6.6 导出

- 高清 PNG：黑白模式使用更高倍率渲染，适合直接插入 Word。
- SVG：保持矢量清晰度，可在矢量编辑器或支持 SVG 的办公软件中继续编辑。
- 保存源文件：普通图表保存为 `.txt`；E-R 图 SQL 模式保存为 `.sql`。
- 复制到 Word：数据库三线表和环境配置表支持富文本复制，中文宋体、英文 Times New Roman、五号字、内容居中，并保留规范三线表边框。

## 7. E-R 图

E-R 图支持两种输入方式，软件会自动判断，无需手动切换。

### 7.1 简洁文本模式

```text
@title 在线选课系统 E-R 图
学生: 学号(PK), 姓名, 专业
课程: 课程号(PK), 课程名, 学分
选课记录: 记录ID(PK), 学号(FK), 课程号(FK), 成绩
学生 1 -- n 选课记录 : 选修
课程 1 -- n 选课记录 : 对应
```

规则：

- `实体名: 属性1, 属性2` 定义实体及属性。
- 属性后添加 `(PK)` 表示主键。
- `(FK)` 可用于源文本说明，但图中不会显示 `FK` 字样。
- `实体A 1 -- n 实体B : 关系名` 定义关系。
- 关系支持 `1 -- 1`、`1 -- n` 和 `n -- n`。

### 7.2 SQL 自动生成模式

在 E-R 图页面点击“SQL 示例”，或直接粘贴 MySQL 建表语句：

```sql
@title 订单系统数据库 E-R 图
CREATE TABLE `user` (
  `id` BIGINT NOT NULL COMMENT '用户ID',
  `name` VARCHAR(50) NOT NULL COMMENT '用户名',
  PRIMARY KEY (`id`)
) COMMENT='用户';

CREATE TABLE `orders` (
  `id` BIGINT NOT NULL COMMENT '订单ID',
  `user_id` BIGINT NOT NULL COMMENT '用户ID',
  `amount` DECIMAL(10,2) COMMENT '订单金额',
  PRIMARY KEY (`id`),
  CONSTRAINT `fk_orders_user`
    FOREIGN KEY (`user_id`) REFERENCES `user` (`id`)
) COMMENT='订单';
```

自动识别内容：

- `CREATE TABLE` 和 `CREATE TABLE IF NOT EXISTS`。
- 反引号、普通标识符和带数据库名前缀的表名。
- 表级或字段级 `PRIMARY KEY`。
- `FOREIGN KEY ... REFERENCES ...` 外键关系。
- `UNIQUE`、唯一索引和主键外键，用于判断一对一关系；普通外键默认生成一对多关系。
- 表 `COMMENT` 作为实体中文名称。
- 字段 `COMMENT` 作为属性中文名称。
- SQL 块注释、`--` 注释和 `#` 注释。

当前限制：

- 解析器优先适配常见 MySQL DDL，不执行 SQL，也不会连接数据库。
- 只解析 `CREATE TABLE` 内部声明的外键，暂不解析后续 `ALTER TABLE ... ADD CONSTRAINT`。
- 被引用表也需要出现在输入文本中，才能生成关系。
- 每个实体当前最多在图中展示前 8 个属性；可通过精简字段或拆分图表改善可读性。
- 自动生成的关系名默认为“关联”；如需自定义关系名称，可改用简洁文本模式定义关系。

## 8. 其他图表输入格式

### 8.1 用例图

```text
@title 校园二手交易平台用例图
system 校园二手交易平台
actor 学生用户
学生用户 -> 用户登录
用户登录 -> 找回密码: extend
商品浏览 -> 查看详情: include
```

系统边界支持鼠标拖动调整大小；右下角不会显示可见的方块手柄。

### 8.2 系统架构图

```text
@title 校园二手交易平台系统架构
表现层: 移动端小程序; Web 管理后台
接口层: REST API; WebSocket; 权限拦截器
业务层: 用户服务; 商品服务; 订单服务
数据层: MySQL; Redis; 对象存储
```

冒号前为层名，冒号后使用分号分隔模块。

### 8.3 功能模块图

```text
@title 图 4.2 系统功能模块图
system 二手交易平台
学生用户: 浏览搜索商品; 发布管理商品; 注册登录
管理员用户: 商品管理; 用户管理; 订单管理
```

### 8.4 类图

```text
class 学生 | +学号: String; +姓名: String | +选课(): Boolean
学生 1 --> n 选课记录 : 发起
```

类名、属性、方法用竖线分隔；属性和方法内部用分号分隔。

### 8.5 时序图

```text
participant 用户
participant Web 前端
用户 -> Web 前端: 提交登录信息
Web 前端 --> 用户: 返回登录结果
```

`->` 表示调用，`-->` 表示返回；参与者在顶部和底部均显示名称方框。

### 8.6 流程图

```text
开始 [start]
输入账号密码 [process]
校验登录信息 [decision]
登录成功 [end]
开始 -> 输入账号密码
输入账号密码 -> 校验登录信息
校验登录信息 -通过-> 登录成功
```

### 8.7 三线表、环境配置表与数据图

表格和实验数据使用逗号或制表符分隔。首行为表头，其余行为数据。例如：

```text
@title 不同并发量下的平均响应时间
并发用户数,优化前,优化后
50,126,82
100,238,141
```

实验数据图可在右侧切换柱状图或折线图。

## 9. 本地数据与隐私

- 源文本、每个图表的样式参数和编辑区布局保存在浏览器 `localStorage` 中。
- 页面刷新后会自动恢复。
- 不同浏览器、无痕窗口和不同设备之间不会自动同步。
- 清理浏览器站点数据会删除本地保存内容，重要内容请及时使用“保存源文件”。
- 当前版本不需要数据库、账号系统或云端文件存储。

## 10. 常见问题

### 10.1 SQL 粘贴后没有生成实体

确认文本包含完整的 `CREATE TABLE 表名 (...)`，左右括号闭合，并优先使用 MySQL 常见语法。若外键通过 `ALTER TABLE` 添加，请暂时将外键声明移动到对应 `CREATE TABLE` 内部。

### 10.2 关系没有生成

确认外键包含 `FOREIGN KEY (...) REFERENCES 表名 (...)`，且被引用表也在输入区中。表名前缀和大小写会自动兼容，但名称必须能对应。

### 10.3 图形重叠

依次尝试“自动排版”、增大“整体间距”、减小“正文字号”或“边框大小”，然后点击“适应全部”。

### 10.4 导出的文字模糊

优先使用 SVG；必须使用 PNG 时选择“导出高清 PNG”。黑白模式会采用更高倍率输出。

### 10.5 双击文字无法修改

复杂结构请直接修改左侧源文本。SQL 模式下，中文显示名称通常来自 `COMMENT`，直接修改相应注释最稳定。

### 10.6 Word 中三线表线条异常

使用页面上的“复制到 Word”按钮，不要从预览画布直接复制。粘贴时优先选择“保留源格式”。
