# 图研 · 部署上线与盈利策划方案

> 方案版本：1.0  
> 编制日期：2026-08-06  
> 目标：低成本上线、降低服务器负担、建立可持续且不损害论文用户体验的盈利模式。

## 1. 执行摘要

图研最适合采用“静态优先、计算在端、服务端按需增加”的上线策略。

当前核心能力——文本解析、SQL 解析、SVG 排版、PNG/SVG 导出、Word 三线表复制——均可在用户浏览器中完成。因此首个线上版本不应急于引入账号、数据库、文件上传和服务端渲染。将站点部署到 CDN/边缘静态托管后，服务器只负责发送前端文件，用户的论文内容和 SQL 不离开设备，可以同时获得低成本、高并发和隐私优势。

推荐商业路线：

1. 免费基础工具建立搜索流量和口碑。
2. 通过“毕业季通行证、专业模板、批量导出、项目历史、学校格式包”等效率能力收费。
3. 后期面向导师团队、实验室和院校提供席位授权与私有部署。
4. 不出售用户论文或数据库结构，不依赖干扰性广告，不把水印作为付费墙。

## 2. 产品定位

### 2.1 核心用户

- 计算机科学与技术、软件工程、网络工程、信息管理等专业本科毕业生。
- 指导毕业设计的教师、实验室和课程设计团队。
- 提供论文格式辅导或软件开发实训的合规教育机构。
- 需要快速整理 UML、数据库和实验图表的开发者。

### 2.2 核心价值

- 输入门槛低：结构化文本和 SQL 均可直接生成图。
- 论文适配强：白底黑字、宋体/Times New Roman、高清 PNG、可编辑 SVG、规范三线表。
- 隐私风险低：默认本地处理，不上传论文和 SQL。
- 调整效率高：实时预览、拖拽、吸附、自动排版、独立样式参数。
- 使用成本低：无需安装重量级桌面建模软件。

### 2.3 差异化原则

- 聚焦“论文最终交付”，而不是泛用绘图。
- 用论文推荐顺序组织工具，而不是按技术名词堆放菜单。
- 基础导出无水印，收费点放在节省时间和团队能力上。
- 明确学术诚信边界：帮助表达和排版，不代写论文、不伪造数据。

## 3. 推荐上线架构

### 3.1 第一阶段：零业务后端

```text
用户浏览器
  ├─ 文本 / SQL 解析
  ├─ 图表布局与拖拽
  ├─ SVG / PNG 导出
  ├─ Word 富文本复制
  └─ localStorage 本地保存
          │
          ▼
CDN / 静态资源托管
  ├─ HTML
  ├─ JavaScript
  ├─ CSS
  └─ 图标等静态资源
```

这一阶段不需要：

- 用户数据库。
- SQL 上传接口。
- 图片转码服务器。
- 文件存储桶。
- 常驻应用服务器。
- Redis、消息队列和后台管理系统。

### 3.2 推荐部署路线

#### 路线 A：国际与快速验证

使用 Cloudflare Workers Static Assets 或 Pages 承载站点：

- 当前项目已具备 Cloudflare Worker 入口和兼容构建结构。
- 静态资源可通过全球网络分发。
- 官方定价说明中，静态资源请求免费且不限量；Workers 免费计划的动态请求存在每日额度，付费计划有最低月费和更高额度。实际价格在购买前应再次核对。
- Pages 免费计划单站文件数量和单文件大小有限制，但本项目资源规模远低于常见上限。

适合：产品验证、海外访问、开发预览、无需中国内地节点的早期版本。

#### 路线 B：中国内地正式运营

使用境内云厂商的对象存储 + CDN，或轻量静态站点托管：

- 域名完成实名认证。
- 根据接入商流程办理 ICP 备案。
- CDN 开启 HTTPS、压缩、缓存和访问日志的最小化配置。
- 若提供付费服务、用户账号、公开内容或其他经营性功能，应在上线前让接入商和专业顾问确认备案、许可、支付、隐私和税务要求。

适合：主要用户位于中国内地、强调访问稳定性和支付便利性的正式版本。

#### 路线 C：双区域

- 主域名使用中国内地 CDN。
- 海外域名或备用域名使用 Cloudflare。
- 构建产物保持一致，通过自动化流水线同时发布。
- 用户数据不跨区域同步；首期仍然全部保存在浏览器本地。

适合：用户规模扩大后，同时覆盖境内高校和海外留学生。

### 3.3 上线步骤

1. 购买简短、易记、与“图研”品牌一致的域名。
2. 确认商标、域名和产品名称没有明显冲突。
3. 运行 `npm ci` 和 `npm run build`，保证生产构建通过。
4. 将构建接入 Git 仓库的主分支发布流程。
5. 部署到预发布域名，验证首页、所有图表、PNG/SVG 导出、Word 复制和移动端布局。
6. 配置 HTTPS、强制跳转、压缩、缓存、安全响应头和故障回滚。
7. 配置自定义域名和 DNS。
8. 若使用中国内地基础设施，先完成备案和必要合规流程，再正式开放域名。
9. 发布隐私说明、服务条款、退款规则、学术诚信说明和联系渠道。
10. 小范围邀请 30–100 名真实毕业生试用一周，再扩大公开推广。

## 4. 降低服务器负担的详细方案

### 4.1 坚持浏览器端计算

- SQL 解析器只读取用户粘贴的 DDL 文本，不连接数据库。
- 图表布局使用浏览器中的 SVG 计算。
- PNG 通过 Canvas 在本地生成。
- SVG 直接在本地序列化。
- Word 表格通过剪贴板富文本在本地构建。

收益：核心操作不消耗服务器 CPU，不产生上传带宽，不保存敏感论文内容。

### 4.2 静态资源缓存

- 文件名使用内容哈希。
- 带哈希的 JavaScript、CSS 和图片设置一年强缓存：`Cache-Control: public, max-age=31536000, immutable`。
- HTML 使用短缓存或协商缓存，保证新版本能及时生效。
- 开启 Brotli/Gzip 压缩。
- 不引入大型在线中文字体；优先使用系统宋体、黑体、楷体等，避免数 MB 字体下载。

### 4.3 减少首屏体积

- 首页只加载基础导航和介绍。
- 图表解析器按图表类型拆分，进入对应工作台时再加载。
- 将导出逻辑和较重的解析器按需加载。
- 不为“待完善”页面加载无效代码。
- 定期检查 JavaScript 包体积和重复依赖。

### 4.4 离线与重复访问

第二阶段可加入 PWA：

- 缓存应用外壳，使用户断网也能继续编辑。
- 新版本采用提示更新，不强制刷新导致内容丢失。
- 所有编辑内容继续保存在本地。

这会显著减少毕业季高峰期间的重复资源请求。

### 4.5 账号与付费功能按需服务端化

不要因为收费就把所有功能搬到服务器。建议：

- 支付完成后签发短小的授权凭证。
- 浏览器缓存授权状态，按 3–7 天进行一次轻量校验。
- 非敏感高级模板可以随前端发布，通过授权状态解锁。
- 只有云同步、团队空间和订单管理访问后端。
- 批量导出仍在浏览器或 Web Worker 中完成。

### 4.6 云同步的最小化设计

若后期加入云同步：

- 默认关闭，由用户明确选择开启。
- 只存源文本、样式参数和版本元数据，不存 PNG 中间文件。
- JSON 压缩后上传；相同版本按内容哈希去重。
- 免费用户限制项目数量和历史版本数。
- 删除项目时同步删除版本和附件。
- 对休眠超过一定期限的免费项目进行提醒后清理。

### 4.7 动态接口保护

- 登录、授权和支付回调设置速率限制。
- 所有付费接口进行幂等处理。
- 设置 Worker CPU 时间和账单预警，防止异常请求造成费用失控。
- 错误日志不得记录论文正文、SQL 原文或导出的图表内容。
- 分析数据只采集页面、图表类型、按钮事件和匿名性能指标。

## 5. 商业模式

### 5.1 免费版

永久免费保留：

- 基础图表创建。
- 本地保存。
- 元素拖拽与自动排版。
- 白底黑字模式。
- 基础 PNG 和 SVG 导出。
- SQL 生成 E-R 图。
- 无水印。

免费版承担获客和口碑作用。限制核心导出或强制水印会显著降低学生推荐意愿，不建议采用。

### 5.2 毕业季通行证

建议价格：`¥29.9 / 180 天`。

可包含：

- 项目文件夹与多图统一管理。
- 自动版本历史。
- 批量导出论文整章图表。
- 高级论文模板和学校格式包。
- 图号连续编号与题注检查。
- 一键导出 Word/LaTeX 素材包。
- 图表规范检查和重叠检测。

180 天比按月订阅更符合毕业设计周期，也能减少忘记取消订阅引起的投诉。

### 5.3 个人专业版

建议价格：`¥59 / 年`。

面向课程设计、研究生和开发者，增加：

- 跨设备同步。
- 更多项目和历史版本。
- 自定义主题和机构模板。
- 优先体验新图表。
- 无广告和更高批量任务额度。

### 5.4 模板与格式包

建议价格：`¥9.9–29.9 / 套`。

示例：

- 软件开发类论文完整图表包。
- 教务管理系统模板包。
- 商城、博客、医院挂号、在线考试等常见毕设模板。
- 指定高校论文图表字号、图题、表题和编号规则包。

模板必须作为结构示例，明确要求用户替换为自己的系统内容，避免诱导论文雷同。

### 5.5 教师与团队版

建议价格：

- 教师团队版：`¥399 / 年 / 10 席位`。
- 实验室或院系版：`¥2,999–5,999 / 年 / 100 席位`。
- 私有部署：`¥6,999 起 / 次`，后续维护 `¥1,999 起 / 年`。

团队能力：

- 统一论文图表规范。
- 模板库和示例库管理。
- 作业链接或只读分享。
- 批量检查图表字号、线宽和标题。
- 校内私有部署和品牌配置。

### 5.6 合作收入

- 与正版开发工具、云服务学生计划、论文排版服务建立清晰标注的推荐合作。
- 与高校实验室或课程教师合作制作公开模板。
- 不接受代写、数据伪造、论文买卖类广告。
- 不出售用户输入、SQL、论文主题或行为画像。

## 6. 收入测算

以下为内部规划假设，不是收益承诺；未包含全部税务差异，支付通道费率、退款率、获客成本和云价格需在运营地区上线前复核。

### 6.1 月度情景模型

| 指标 | 保守期 | 基准期 | 增长期 |
| --- | ---: | ---: | ---: |
| 月活跃用户 | 10,000 | 50,000 | 200,000 |
| 个人付费转化率 | 1.5% | 2.5% | 3.0% |
| 个人客单价 | ¥29.9 | ¥32 | ¥35 |
| 个人付费收入 | ¥4,485 | ¥40,000 | ¥210,000 |
| 模板包收入 | ¥1,290 | ¥9,000 | ¥36,000 |
| 团队/私有部署月均收入 | ¥500 | ¥8,500 | ¥44,000 |
| 预计月收入 | **¥6,275** | **¥57,500** | **¥290,000** |
| 基础设施与工具 | ¥300 | ¥1,500 | ¥5,000 |
| 内容、客服与研发人力 | ¥1,500 | ¥10,000 | ¥80,000 |
| 推广费用 | ¥1,500 | ¥15,000 | ¥60,000 |
| 支付、退款、财务与合规预留 | ¥463 | ¥4,075 | ¥19,000 |
| 预计月经营贡献 | **约 ¥2,512** | **约 ¥26,925** | **约 ¥126,000** |

### 6.2 盈亏平衡示例

假设：

- 每月固定运营成本为 ¥14,000。
- 每位个人付费用户扣除支付、退款和服务成本后的平均贡献为 ¥31。
- 暂不计算团队版收入。

则个人付费用户盈亏平衡点约为：

```text
14,000 ÷ 31 ≈ 452 人/月
```

若个人付费转化率为 2%，需要的月活跃用户约为：

```text
452 ÷ 2% ≈ 22,600 MAU
```

获得团队版收入后，个人付费用户的盈亏平衡要求会下降。

### 6.3 关键财务纪律

- 早期不雇佣超过实际收入承受能力的全职团队。
- 单个渠道的获客成本不超过预计用户贡献的 30%。
- 每月设置云账单硬预警和预算上限。
- 年付收入按服务期确认，不把全部现金视为当月利润。
- 预留退款、税费、发票和客服成本。
- 任何定价实验至少观察一个完整毕业季周期。

## 7. 获客方案

### 7.1 搜索流量

建设独立帮助页面和示例页，覆盖：

- E-R 图在线生成。
- SQL 转 E-R 图。
- 毕业论文三线表。
- 系统功能模块图怎么画。
- 用例图、时序图、类图论文示例。
- 五号字对应多少像素。

每个页面提供可立即编辑的示例，而不是只写概念文章。

### 7.2 内容传播

- Bilibili、抖音、小红书发布 1–3 分钟操作教程。
- Gitee/GitHub 发布公开基础版本或示例仓库，建立开发者可信度。
- 在毕业季前按章节发布“论文图表检查清单”。
- 制作脱敏的真实改图案例，展示“修改前/修改后”。

### 7.3 校园合作

- 邀请 5–10 位指导教师试用团队版。
- 为课程设计提供统一模板和课堂演示。
- 建立校园推荐员计划，但不得诱导论文代写。
- 推荐奖励优先使用会员天数或模板券，控制现金推广成本。

### 7.4 季节性运营

- 9–11 月：选题、需求分析、数据库设计内容。
- 12–2 月：总体设计、详细设计和系统实现图表。
- 3–5 月：论文定稿、图表规范检查、批量导出。
- 6–8 月：课程设计、产品迭代、院校合作和模板生产。

## 8. 转化漏斗与指标

### 8.1 核心漏斗

```text
访问首页
  → 进入图表工具
  → 成功生成第一张图
  → 完成一次导出
  → 创建第二张图
  → 查看高级能力
  → 购买
```

### 8.2 建议指标

- 首张图成功率：访问工作台后成功生成非空图表的比例。
- 首次价值时间：从打开页面到首次导出的中位时长，目标小于 5 分钟。
- 导出率：进入工作台后完成 PNG、SVG 或 Word 操作的比例。
- 多工具使用率：7 天内使用两种以上图表的用户比例。
- 付费转化率：目标先验证 1.5%，再逐步优化至 2%–4%。
- 退款率：目标低于 3%。
- 每百名活跃用户的客服工单数。
- 单次会话前端错误率和导出失败率。

分析系统不得采集源文本、SQL 内容、图表文字和剪贴板内容。

## 9. 12 周执行计划

### 第 1–2 周：公开测试

- 完成域名、隐私说明、服务条款和反馈流程。
- 部署静态优先版本。
- 邀请 30–100 名学生试用。
- 修复 SQL 兼容、导出、Word 粘贴和不同屏幕布局问题。

### 第 3–4 周：增长基础

- 建立帮助中心和示例页。
- 加入匿名、隐私友好的事件统计。
- 建立错误告警、性能监控和版本回滚。
- 优化首屏包体和缓存策略。

### 第 5–6 周：付费最小版本

- 接入合规支付渠道。
- 实现订单、授权凭证、退款和客服后台。
- 上线毕业季通行证。
- 首批高级功能只选择批量导出、项目历史和模板包。

### 第 7–8 周：项目与同步

- 增加项目文件夹。
- 开发用户主动开启的轻量云同步。
- 增加版本历史、导入和备份。
- 完成数据导出和账号删除流程。

### 第 9–10 周：内容商品化

- 发布 3–5 套高质量模板包。
- 建立模板审核、版本和兼容机制。
- 制作对应教程和示例项目。

### 第 11–12 周：B2B 验证

- 邀请教师和实验室试用。
- 验证统一模板、批量检查和私有部署需求。
- 只在获得明确订单信号后开发复杂团队功能。

## 10. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 毕业季流量集中 | 短期高并发 | 静态 CDN、浏览器端计算、预热缓存、账单预警 |
| SQL 方言差异 | 图表生成错误 | 标明 MySQL 优先；增加解析测试；提供简洁文本兜底 |
| 论文内容泄露担忧 | 用户不敢使用 | 默认不上云；页面明确提示；日志不记录输入内容 |
| 模板导致论文雷同 | 学术风险 | 模板只给结构；要求替换内容；加入学术诚信声明 |
| 付费功能价值不足 | 转化率低 | 基础功能免费；先验证批量导出、历史和格式包 |
| 国内访问不稳定 | 转化下降 | 境内 CDN + 备案；海外备用；监控不同区域性能 |
| 支付与许可合规 | 下架或处罚 | 接入持牌渠道；上线前进行专业合规审查 |
| 恶意请求导致账单异常 | 成本失控 | 静态优先、限流、CPU 限制、预算和异常告警 |

## 11. 合规与隐私清单

- 发布隐私政策，明确哪些信息保存在本地、哪些会发送到服务器。
- 未开启云同步时，不上传源文本、SQL 和图表内容。
- 云同步必须主动选择，并提供导出和删除入口。
- 支付订单与图表内容分离存储。
- 日志、客服截图和错误报告设置保留期限。
- 使用第三方分析、支付或邮件服务时，在隐私政策中列出用途。
- 若在中国境内提供网站服务，按适用要求办理备案；经营性服务、教育相关宣传和支付模式需结合实际业务进行专业审核。
- 页面底部展示必要的备案、主体和联系信息。
- 明确禁止代写、伪造实验数据和侵权模板上传。
